# Build Your Own HTTP Server

A project to understand how HTTP works by implementing an HTTP server from scratch in C# using .NET and TCP sockets.

## About

This project is part of my **Build Your Own** series, where I recreate core software systems from scratch to gain a deeper understanding of how they work internally.

Rather than using ASP.NET Core or existing web frameworks, this project builds an HTTP server directly on top of TCP sockets.

## Features (Planned)

- [ ] TCP server
- [ ] Accept client connections
- [ ] Parse HTTP requests
- [ ] Generate HTTP responses
- [ ] Support GET requests
- [ ] Basic routing
- [ ] Serve static files
- [ ] Handle multiple clients

## Tech Stack

- C#
- .NET 10
- TCP Sockets
